# Portfólio — Arthur Monsores

Site pessoal de Arthur Monsores, desenvolvedor de software no Rio de Janeiro (RJ), com foco em automação de processos, IA aplicada e Business Intelligence.

🔗 **Acesse em produção:** [monsoresport.vercel.app](https://monsoresport.vercel.app)

## Sobre

Trabalho com automação de processos usando n8n, integração de agentes de IA em fluxos de trabalho, backend com Django e PostgreSQL e Business Intelligence com Power BI e Metabase. Atualmente atuo na Interligados Soluções em Tecnologia, com foco em BI, testes de funcionalidades e desenvolvimento com apoio de IA aplicado a sistemas de negócio.

## Stack

Python · Django · PostgreSQL · SQL · n8n · Docker · Power BI · Metabase · JavaScript

## Rodando localmente

O site é HTML/CSS/JS estático, sem build step. Basta servir a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
```

E abrir `http://localhost:8000`.
